# Payroll V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deepen payroll into a configurable gross-to-net engine with earnings, allowances, scoped assignments, stronger readiness blockers, and matching admin controls.

**Architecture:** Extend the existing HCM setup contract with earning policies and richer blocker conditions. Keep payroll calculation inside `PayrollCycleCalculationService`, governance inside `PayrollCycleGovernanceService`, and expose only wired controls in the existing payroll admin page.

**Tech Stack:** NestJS, TypeScript, Vitest, React, Vite, TanStack Query, Radix UI.
