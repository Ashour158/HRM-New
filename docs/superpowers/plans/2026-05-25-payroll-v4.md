# Payroll V4 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make payroll inputs, close-to-pay, mass update, payment export, and payslip outputs more complete and governed.

**Architecture:** Keep gross-to-net math in `PayrollCycleCalculationService`, add a focused input orchestration service for payroll input drafts and payment artifacts, and keep command-bus execution in the controller. Replace placeholder saga wiring with active-cycle resolution so event-driven payroll inputs are connected to real cycles or skipped explicitly.

**Tech Stack:** NestJS, TypeScript, Kysely repositories, Vitest, React/Vite.
